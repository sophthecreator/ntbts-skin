## how to add the skin to ao3
please note: you must be logged into ao3 to create a site skin and use it.

1. find the code by looking for the file titled "ntbts-skin" above.
2. open your ao3 dashboard by tapping your username in the top right corner and selecting it from the dropdown menu.
3. find the section titled "skins" on the right sidebar.
4. press the button labeled "create site skin".
5. title it anything you'd like. it is important to note that ao3 only allows unique names for site skins. you can ensure that your site skin title is unique by naming it something like "site skin name [your username here]".
6. paste the code found in step 1 into the box titled css.
7. scroll down and press "submit".
8. you will be taken to a page that shows you the title of the skin and all of its code. 
9. on the site skin page, tap on the button that says "use". the site skin will be saved and will be visible on every device you are logged in on.
